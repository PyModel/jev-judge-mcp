## Not measured

- Agent temperature: not settable through the Claude Code CLI; its default, identical in every arm.
- Billed Jev price: TypeSafe exposes no per-request bill; Jev cost is the published $0.042/M input rate times the input tokens each tool result reports. The $0.042/M claim is applied, not verified.
- Billed agent price: the agent cost is the Claude Code CLI's `total_cost_usd` (cost basis `list`), not an invoice.
- Provider latency alone: the proxy times each `tools/call` round trip, which includes the server's local validation, policy, and serialization. It is an upper bound on TypeSafe latency, not the latency itself.
- Variance: one run per task and arm.
- Jev provider latency (the 70-500 ms claim) and Jev spend: no B or C run called a Jev tool, so there is no round trip to time and no token count to price.
